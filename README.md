# Botica Nova Salud - Sistema Web de Gestión de Inventario y Ventas (POS)
Proyecto de software desarrollado para el Trabajo Final del curso Fullstack Developer en SENATI.

## Tecnologías Utilizadas
- **Frontend:** React.js, Vite, Axios, Tailwind CSS
- **Backend:** Node.js, Express.js (API REST)
- **Base de Datos:** MongoDB Atlas (Mongoose)
- **Seguridad (5 Capas):** Helmet, CORS, Rate Limit, HTTPS, Morgan Logs

## Requisitos previos
- Node.js v18+
- Cuenta en MongoDB Atlas

## Instalación y Configuración
1. Clonar el repositorio: `git clone https://github.com/Samir22bot6/botica-nova-salud.git`
2. Configurar variables de entorno en `backend/.env` según `backend/.env.example`.
3. Ejecutar `npm install` tanto en `backend` como en `frontend`.
4. Iniciar en modo desarrollo: `npm run dev`
